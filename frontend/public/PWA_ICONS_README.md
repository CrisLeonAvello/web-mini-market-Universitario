# Iconos PWA

Los íconos necesarios para la PWA deben estar en `frontend/public/`:

- `icon-192.png` (192x192)
- `icon-512.png` (512x512)
- `apple-touch-icon.png` (180x180)
- `favicon.ico` (32x32)

## Generar íconos rápidamente:

1. **Opción fácil:** Usa https://realfavicongenerator.net/
   - Sube un logo
   - Descarga el paquete completo
   - Copia los archivos a `public/`

2. **Opción manual:** 
   - Crea una imagen 512x512 con tu logo
   - Usa herramientas online para redimensionar

## Comando para instalar la app:

Una vez levantado el servidor:
1. Abre Chrome/Edge en el móvil
2. Ve a http://localhost:5173
3. Menú → "Instalar app"
4. ¡Listo! Aparecerá como app en tu teléfono
